# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

An [awesome list](https://awesome.re) of **free and open-access** resources for tracking internet trends (social media and general analytics). The list lives in `README.md`, contribution rules in `CONTRIBUTING.md`, and it is licensed CC0 (badge in the README's License section; there is no LICENSE file). There is no code, build, lint, or test tooling.

## Editing conventions

- Entry format (match exactly):
  `- [Name](https://url) - One-sentence description. **Free and open to access.**`
- Only add resources that are free and open to access; that is the list's inclusion criterion.
- Sections: `Open-source Projects`, `Social Media Trends`, `General Trend Analytics`, `Contributing`, `License`. If you add, rename, or remove a section, update the `## Contents` list at the top so its anchor links still resolve, and keep `CONTRIBUTING.md` in sync with these rules.
